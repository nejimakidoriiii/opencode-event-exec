# プレースホルダーは実在フィールドのみ参照し、欠落時はリテラルを透過

プレースホルダー `{event}` / `{sessionID}` / `{agent}` / `{model}` / `{created}` / `{data}` は OpenCode v2 イベントの実フィールドのみを参照し、sessionID からの名前解決や永続カウンターを必要とする値(`{turn}` 等)は提供しない。参照先がイベントに存在しない場合、空文字列への置換も実行スキップもせず、`{agent}` のリテラル文字列のまま引数に渡す。類似システムの多くは空文字列へ置換するが、「置換されなかった」ことを利用者が引数値から判別できることを優先した。名称を v2 のフィールド名に合わせた(`{timestamp}` ではなく `{created}`。v2 イベントに timestamp フィールドは存在せず、トップレベルの `created`= エポックミリ秒が対応)のは、「ペイロードに直接含まれる値のみを提供する」原則との整合のため。
