# イベントタイプ名は完全一致のみ。抽象イベント名・ワイルドカード・ペイロード条件を導入しない

ルールの `event` は OpenCode v2 のイベントタイプ名との完全一致のみとし、`session.*` のようなワイルドカード、permission / complete / error のような抽象イベント名、`data.status.type == 'idle'` のようなペイロード条件を導入しない。mohak34/opencode-notifier 互換の抽象名は v2 のイベント再編で対応関係が保てず、本プラグインの識別性(設定に書いた名前が v2 のストリームにそのまま現れる)を損なうため明示的に拒否する。

## Consequences

- 「セッションがアイドルになったときだけ発火」は `session.status`(busy / retry でも発火が広がる)では表現できず、非推奨(deprecated)の `session.idle` を登録する以外にない。これは仕様であり、ドキュメントで両者の差を明記する。
- v2 でイベントタイプが追加されても、未知のイベントタイプ名は利用者が登録した範囲でだけ意味を持つため、既存設定は壊れない。
